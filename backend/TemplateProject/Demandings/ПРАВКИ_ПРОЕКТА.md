```json
// В appsettings.Development.json добавьте:
{
  "Mailtrap": {
    "ApiToken": "YOUR_MAILTRAP_API_TOKEN",
    "SenderId": "YOUR_MAILTRAP_SENDER_ID",
    "SenderEmail": "noreply@meetingsystem.local"
  }
}
```

**Где получить:**
1. Зарегистрируйтесь на https://mailtrap.io (даром 100 письм/месяц)
2. Перейдите в Email Sending → Integrations → API
3. Скопируйте токен и Sender ID
4. Обновите значения в `EmailNotificationService.cs` (строки с `TODO`)

#### Использование:
```csharp
// В любом обработчике команды/запроса:
var emailService = serviceProvider.GetRequiredService<IEmailNotificationService>();
await emailService.SendMeetingInvitationAsync(user, meeting, cancellationToken);
```

#### Сохраненные данные в Message:
- `Id` — уникальный ID сообщения
- `SenderId` / `RecipientId` — отправитель и получатель
- `Subject` — тема письма
- `Body` — содержимое письма (HTML)
- `SentAt` — дата и время отправки
- `IsRead` / `ReadAt` — статус прочтения
- `MeetingId` — связь с встречей (опционально)

### 2. **Refresh Tokens / Продление Сессии** 🔄

#### Текущая ситуация:
Ваш проект использует JWT токены с временем жизни **5 часов** (`appsettings.Development.json`).

#### Предложение 1: **Увеличить время жизни Access Token** (Простейший вариант)
```json
"Auth": {
  "Lifetime": "24:00:00"  // Вместо "05:00:00"
}
```

**Плюсы:**
- ✅ Не нужно менять логику на фронте
- ✅ Простая реализация

**Минусы:**
- ❌ Небезопасно (если токен украден, доступ на сутки)
- ❌ Нет способа быстро заблокировать доступ

#### Предложение 2: **Добавить Refresh Token** (Рекомендуется)
```
Access Token: 15 минут (короткий)
Refresh Token: 7 дней (длинный, хранится в БД)
```

**Плюсы:**
- ✅ Безопаснее (Access Token вален мало)
- ✅ Можно без переввода заново в систему
- ✅ Возможность отзыва токена

**Минусы:**
- ⚠️ Нужно создать таблицу `RefreshTokens`
- ⚠️ Требуется эндпоинт `/api/v1/auth/refresh`
- ⚠️ Нужны изменения на фронте (сохранение refresh token отдельно)

#### Предложение 3: **Использовать HttpOnly Cookies** (Самое безопасное)
```csharp
Response.Cookies.Append("refreshToken", token, 
    new CookieOptions 
    { 
        HttpOnly = true,  // Недоступен JavaScript
        Secure = true,    // Только HTTPS
        SameSite = SameSiteMode.Strict,
        Expires = DateTimeOffset.UtcNow.AddDays(7)
    });
```

**Плюсы:**
- ✅ Максимальная безопасность (CSRF защита встроена)
- ✅ Не доступна JavaScript
- ✅ Автоматически отправляется в запросах

**Минусы:**
- ⚠️ Нужные изменения в CORS конфигурации
- ⚠️ Требуется поддержка credentials на фронте

### 3. **Soft Delete для пользователей** 🗑️

#### Что создано:
- **Поля в User:**
  - `IsDeleted` — флаг удаления
  - `DeletedAt` — время удаления
  - `DeletedBy` — какой администратор удалил

- **Эндпоинты:**
  - `DELETE /api/v1/users/{id}` — мягкое удаление (обновлено)
  - `PATCH /api/v1/users/{id}/restore` — восстановление пользователя
  - `GET /api/v1/users/deleted` — просмотр удаленных пользователей

- **Обновленная логика:**
  - `GET /api/v1/users` — теперь показывает только активных (не удаленных)
  - При удалении проверяется: активные встречи, загруженные файлы

#### Использование:

**Удалить пользователя:**
```bash
DELETE /api/v1/users/{userId}
```

**Просмотр удаленных:**
```bash
GET /api/v1/users/deleted?page=1&limit=20
```

**Восстановить пользователя:**
```bash
PATCH /api/v1/users/{userId}/restore
```

#### Дополнительная логика:
- Нельзя удалить текущего администратора
- Нельзя удалить, если есть активные встречи
- Нельзя удалить, если есть загруженные файлы
- При восстановлении очищаются `IsDeleted`, `DeletedAt`, `DeletedBy`

### Refresh Token (если выберете Предложение 2):
```typescript
const api = axios.create({
  baseURL: 'https://localhost:7262',
  timeout: 10000
});

api.interceptors.response.use(
  response => response,
  async error => {
    if (error.response?.status === 401) {
      const refreshToken = localStorage.getItem('refreshToken');
      if (refreshToken) {
        const resp = await api.post('/api/v1/auth/refresh', { refreshToken });
        localStorage.setItem('token', resp.data.accessToken);
        return api(error.config);
      }
      // Перенаправить на логин
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);
```
