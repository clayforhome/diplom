## 🔍 Проверка работы

### 1. Email уведомления:
```bash
# 1. Создать встречу
POST /api/v1/meetings
{
  "title": "Test Meeting",
  "description": "Тестовое письмо",
  "date": "2026-05-25",
  "startTime": "2026-05-25T10:00:00",
  "endTime": "2026-05-25T11:00:00",
  "format": "Online",
  "meetingLink": "https://meet.example.com/test"
}

# 2. Пригласить участников
POST /api/v1/meetings/{meetingId}/participants
{
  "participantIds": ["user-id-1", "user-id-2"]
}

# 3. Проверить Mailtrap: https://mailtrap.io/inboxes
# 4. Получить сообщения
GET /api/v1/messages?page=1&limit=10
```

### 2. Soft Delete:
```bash
# 1. Удалить пользователя
DELETE /api/v1/users/{userId}

# 2. Проверить, что пользователь в удаленных
GET /api/v1/users/deleted?page=1&limit=10

# 3. Восстановить пользователя
PATCH /api/v1/users/{userId}/restore

# 4. Проверить, что пользователь в активных
GET /api/v1/users?page=1&limit=10
```
