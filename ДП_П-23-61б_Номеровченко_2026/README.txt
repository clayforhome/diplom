СОСТАВ АРХИВА (по Приложению 5 методических указаний)
-----------------------------------------------------
01_PZ/         - Пояснительная записка (DOCX), индивидуальное задание, презентация (PPTX).
                 ВНИМАНИЕ: добавить PDF-версию ПЗ (экспорт из Word).
02_Schemes/    - ER-диаграмма базы данных (PNG). Схема архитектуры - в ПЗ (§2.2, рис. 2.1).
03_DB/         - Миграции EF Core (создание схемы и таблиц). SQL-скрипты - в ПЗ (Приложение Б).
04_Code/       - Исходный код: backend (ASP.NET Core 9) и frontend (React 18 + TypeScript).
                 Без build-артефактов (bin, obj, node_modules, dist) и без секретов.
                 Конфигурация задается файлами appsettings.Development.json (backend) и .env
                 (frontend) - шаблоны приведены в *.example; реальные значения - через
                 переменные окружения (см. Приложение Д ПЗ).
05_Testing/    - Протоколы тестирования - в ПЗ (§3.8, таблица 3.3; Приложение Г).
06_Screenshots/- Скриншоты интерфейса (вход, панели ролей, встречи, админ-разделы,
                 казахская локализация) и репозитория (история коммитов).
07_Docs/       - README.md с инструкцией установки и запуска (дублируется в Приложении Д ПЗ).
08_Economics/  - Экономические расчеты - в ПЗ (Раздел 4).

СРЕДА ЗАПУСКА
------------
- .NET 9 SDK, Node.js 20+, PostgreSQL 16.
- База данных создается и наполняется тест-данными автоматически при первом запуске backend.

ПОРЯДОК ПРОВЕРКИ
---------------
1. Развернуть PostgreSQL 16.
2. Создать appsettings.Development.json из appsettings.Development.json.example и заполнить.
3. Backend:  cd 04_Code/backend/TemplateProject && dotnet run
4. Frontend: cd 04_Code/frontend && npm install && npm run dev
5. Открыть http://localhost:3000, войти под тестовой учетной записью (см. Приложение Д ПЗ).
